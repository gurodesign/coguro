See Well to Learn

Product Brand Illustration

See Well to Learn was a collaboration by Prevent Blindness Northern California and Tipping Point that offered preschool aged children services related to vision impairedness.

ROLE

Guro Design Project

Principal

OVERVIEW

I had the opportunity to work with Prevent Blindness Northern California to help with their web presence for See Well to Learn, a program that offered mobile vision screenings to preschool children.

The Website

Creating the website for See Well to Learn website we used a mix of existing assets and vector craphics to promote the non-profit program. Because it was mainly a static site I would build it locally and hand off code to be published by their tech team.

Incorporating the mobile screening bus was a no-brainer. Adding the San Francisco backdrop helped localize the program while the rendered vectors help highlight the program features and outcome statistics. The site was well received and eventually led to additional projects that varied in nature.

The following project for PBNC was their annual report. They wanted a value solution for publishing and mailing their annual report. As such it was my job to cram all of their annualized data onto a 8x14" quad-fold. It was a tight fit, but I was happy to get it to work.

Guro Design built an amazing website for our See Well to Learn paid vision screening program! The website does a beautiful job of conveying our programs while maintaining consistent branding. Our customers use it to register their child and pay for the vision screening.
